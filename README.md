# Harmonia Mobile

Native mobile client for **Harmonia**, built with React Native, Expo, Expo Router, and TypeScript.

## Goals

- Fast, phone-first Harmonia experience
- Native Android and iOS UI
- Background audio playback and media controls
- Lock-screen / notification controls
- Shared Harmonia accounts, playlists, library, and APIs
- Smooth mini-player and full-player transitions
- Keep the existing Harmonia web application independent

## Stack

- Expo SDK 57
- React Native 0.86
- React 19.2
- Expo Router
- TypeScript

## Development

```bash
npm install
npx expo start
```

For an Android development build:

```bash
npx expo run:android
```

Cloud builds will be configured with EAS in a later phase.
